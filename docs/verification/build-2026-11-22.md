# ビルド検証記録 (2026-11-22)

目的: NCS v3.4.2 (LTS) + zephyr-lang-rust で `nrf54l15dk/nrf54l15/cpuapp` 向け
Rustアプリケーションが `west build` できることを確認する。

## 環境・ツールバージョン

| 項目 | 値 |
|---|---|
| ベースコミット | 本ブランチ (初コミット `7e7a750` からの派生) |
| NCS | v3.4.2 (`sdk-nrf`), Zephyr `ncs-v3.4.2` (4.4.2) |
| Zephyr SDK | 1.0.1, arm-zephyr-eabi-gcc 14.3.0 |
| west | v1.5.0 (nrfutil sdk-manager toolchain launch 内) |
| cmake | 4.2.1 |
| rustc / cargo | 1.100.0 (rustup, 2026-11-09) |
| clang (bindgen用) | Ubuntu clang 14.0.0 (libclang-dev) |
| zephyr-lang-rust | `dd73abc242e995784da62352fe8c70d9a6c7ac2e` (2025-06-04) |
| Rustターゲット | `thumbv8m.main-none-eabi` |

## コマンド (再現手順)

```sh
# 準備 (一度だけ)
sudo apt-get install -y libclang-dev clang
rustup target add thumbv8m.main-none-eabi
git clone https://github.com/zephyrproject-rtos/zephyr-lang-rust
cd zephyr-lang-rust && git checkout dd73abc... && cd -

# ビルド (既存 NCS v3.4.2 ワークスペース内)
nrfutil sdk-manager toolchain launch --ncs-version v3.4.2 -- bash -c \
  'ZEPHYR_EXTRA_MODULES=<path>/zephyr-lang-rust \
   BINDGEN_EXTRA_CLANG_ARGS="-imacros <ws>/zephyr/include/zephyr/toolchain/zephyr_stdint.h" \
   west build -b nrf54l15dk/nrf54l15/cpuapp -s <repo>/app'
```

## 失敗と対処 (全て解決済み)

| # | 症状 | 原因 | 対処 |
|---|---|---|---|
| 1 | `can't find crate for core` / `thumbv8m.main-none-eabi` 未インストール | Rustターゲット未導入 | `rustup target add thumbv8m.main-none-eabi` |
| 2 | bindgen: `mm.h:48: error: function-like macro '__UINT32_C' is not defined` | `CONFIG_ENFORCE_ZEPHYR_STDINT` では `__UINT32_C` 等がコンパイラ `-imacros zephyr_stdint.h` でのみ注入され、bindgenのclangには伝わらない | `BINDGEN_EXTRA_CLANG_ARGS="-imacros .../zephyr_stdint.h"` |
| 3 | `export_kconfig_bool_options` が `zephyr_build` に無い | ピン版 dd73abc では関数名が `export_bool_kconfig` / `dt_cfgs` で、newer main と異なる。hello_world では不要 | `build.rs` と `zephyr-build` 依存を除去 |

## 結果 (合否基準: zephyr.hex が生成される)

- `west build` 成功、`build/app/zephyr/zephyr.hex` 生成。
- メモリ使用: FLASH 59,428 B / 1,524 KB (3.81%), RAM 12,264 B / 256 KB (4.68%)。
- `arm-zephyr-eabi-nm` で `rust_main` シンボルあり、ELFに
  `Hello world from Rust on ` と `nrf54l15dk` 文字列あり →
  ログメッセージがファームウェアに焼かれていることを確認。
- 未検証: 実機への書き込み・UART出力 (DevinにはDK未接続)。
